Which kind of pressure breaks a model — not how much

Seven pressure types applied to the same prohibition, everything else held fixed. The ladder is ordered but not monotonic: rates rise into instrumental necessity and fall again under authority-based pressure. Across every model the corrosive dose is necessity — the forbidden act becoming the only route to the agent's own goal — not persuasion.

filled = judge-certified or hand-verified hollow = provisional label, awaiting re-certification
Read the hollow points with suspicion. They carry regex or self-commit labels, both of which we have caught being wrong in model-dependent ways — a keyword certifier scores “I step back rather than eating it” as a violation. Where hand-verification has been done it moved numbers materially (Gemma T4 fell from 83% to 50%), so the DeepSeek-R1 14B line in particular should be treated as a shape, not a set of values. Every cell is n = 6–24 across 3 seeds: this is exploratory, sized to show where to look, not to support a claim.
